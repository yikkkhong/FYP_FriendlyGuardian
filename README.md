# Friendly Guardian AI Anti Scam

An AI-powered anti-scam assistant that helps users assess suspicious messages and images

## Modes

### Manual Mode

- Submit a suspicious message or image for analysis.
- Receive an explanation of possible scam indicators.
- Image analysis may identify visual inconsistencies or signs of AI editing.

### Companion Mode

- Chat with the assistant naturally using text or voice commands.
- Ask for recent suspicious notifications or scam messages.
- Planned: monitor notifications and display an alert when a possible scam is detected.

## Project Status

This project is currently in development. Some features are experimental or not yet implemented.
